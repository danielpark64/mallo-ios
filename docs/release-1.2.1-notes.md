# 1.2.1 — 새 기능 문구 (2026-11-24 작성, 제출 대기)

- 바뀐 것: 일정 보내기 버튼을 나라별 메신저에 맞춤(한국 카톡, 일본·대만·태국 LINE, 중국 WeChat, 미국·캐나다 문자, 그 밖 WhatsApp) + 어느 나라든 "다른 앱으로 보내기"(공유 창, 교대알람과 같은 방식).
- **Play는 1.2.0을 건너뛰고 1.2.1로 올린다** → Play 출시 노트는 1.2.0 문구를 그대로 쓴다(`docs/release-1.2.0-notes.md`의 Play 부분, 이미 "메신저·문자"로 일반화돼 있음).
- App Store는 1.2.0이 먼저 나가므로 아래 짧은 문구만 넣는다.
- 번들: `~/Desktop/세이람-1.2.1-vc7.aab`. iOS 빌드 14는 아직 TestFlight에 올리지 않음.
