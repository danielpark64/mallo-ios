# 1.2.1 — 새 기능 문구 (2026-11-24 작성, 제출 대기)

- 바뀐 것: 일정 보내기 버튼을 나라별 메신저에 맞춤(한국 카톡, 일본·대만·태국 LINE, 중국 WeChat, 미국·캐나다 문자, 그 밖 WhatsApp) + 어느 나라든 "다른 앱으로 보내기"(공유 창, 교대알람과 같은 방식).
- **Play는 1.2.0을 건너뛰고 1.2.1로 올린다** → Play 출시 노트는 1.2.0 Play 문구(`docs/release-1.2.0-notes.md`)에 "끄기 화면 맨 앞" 한 줄을 더한 아래 블록을 쓴다(11-24 보강).
- App Store는 1.2.0이 먼저 나가므로 아래 짧은 문구만 넣는다.
- 번들: `~/Desktop/세이람-1.2.1-vc7.aab`. iOS 빌드 14는 11-24 TestFlight 업로드.
- 11-24 보강: App Store에 "알림이 더 눈에 띄게(집중 모드에서도)"(iOS Time Sensitive), Play에 "끄기 화면 맨 앞"(Android 알람 화면 항상 맨 앞) 한 줄씩.
