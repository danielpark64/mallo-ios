## 1. 업로드 키 만들기 (한 번만)

비밀번호를 직접 정해야 해서 이 단계는 직접 실행해야 합니다.

```bash
keytool -genkeypair -v -keystore android/app/release.jks -alias sayram-upload -keyalg RSA -keysize 2048 -validity 10000
```

그다음 `store-assets/keystore.properties.example`을 `android/keystore.properties`로 복사해 방금 정한 비밀번호를 채웁니다.
- `release.jks`와 `keystore.properties`는 커밋되지 않습니다(`*.jks`, `/android` 가 .gitignore에 있음). **두 파일과 비밀번호는 따로 안전한 곳에 보관**하세요.
- Play 앱 서명을 쓰므로 업로드 키를 잃어버려도 Google에 재설정을 요청할 수 있습니다.
- `keystore.properties`가 없으면 지금처럼 debug 키로 서명되어 로컬 테스트 빌드는 계속 됩니다.

## 2. 개인정보처리방침 페이지 열기

교대알람과 같은 방식(GitHub Pages, main 브랜치의 `/docs`)입니다.
1. 이 브랜치를 main에 합칩니다.
2. GitHub 저장소 `danielpark64/mallo-ios` → Settings → Pages → Branch `main`, 폴더 `/docs` → Save.
3. 주소: `https://danielpark64.github.io/mallo-ios/privacy.html` (영문 `privacy-en.html`)

## 3. 업로드 파일(AAB) 만들기

```bash
cd android && ./gradlew bundleRelease
```

결과: `android/app/build/outputs/bundle/release/app-release.aab` → `~/Desktop/세이람-1.0.0-vc1.aab`로 복사해 올립니다.
- versionCode 규칙(교대알람과 동일): 한 번 올린 번호는 출시하지 않았어도 다시 못 씁니다. 제출 전에 코드를 고쳤다면 versionName은 그대로 두고 versionCode만 올립니다(`app.json`의 `android.versionCode`와 `android/app/build.gradle`).
- 심사 중에는 다시 제출하지 않습니다(대기 순서가 처음부터 다시 시작).

## 6. 데이터 보안 양식

- **"앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요?" → 아니요.**
- 근거: 앱에 인터넷 권한이 없어 어떤 데이터도 기기 밖으로 보낼 수 없습니다(빌드의 권한 목록으로 확인). 녹음·일정은 앱 전용 저장소에만 있습니다. 광고·분석 SDK 없음.
- 참고: 음성을 글로 바꾸는 일은 기기의 음성 인식 서비스(Google 음성 서비스 등)가 하며, 이 내용은 개인정보처리방침 2항에 적었습니다. Google의 정의상 "수집"은 앱(과 앱에 포함된 SDK)이 기기 밖으로 전송하는 것을 말하므로 이 앱의 수집에는 해당하지 않는다고 판단했습니다. 더 보수적으로 가려면 "오디오 › 음성 또는 사운드 녹음: 수집됨, 일시적으로 처리, 앱 기능 목적, 공유 안 함"으로 신고할 수도 있습니다. **법적 신고이므로 최종 선택은 직접 해주세요.**
- 나중에 인터넷 권한을 다시 넣으면 이 양식과 등록 문구의 "인터넷 권한 없음" 문단을 함께 고쳐야 합니다.

## 7. 권한 신고 (콘솔이 물어보는 것)

빌드에 들어간 권한: 마이크, 알림, 정확한 알람(USE_EXACT_ALARM/SCHEDULE_EXACT_ALARM), 전체 화면 인텐트, 포그라운드 서비스(미디어 재생), 다른 앱 위에 표시, 부팅 시 시작, 진동, 화면 깨우기.

| 신고 | 적을 내용 |
|---|---|
| 정확한 알람 (USE_EXACT_ALARM) | 핵심 기능이 "캘린더·알람": 사용자가 말로 정한 일정 시각에 알람을 울리는 앱입니다. 사용자가 지정한 시각에 정확히 울려야 합니다. |
| 전체 화면 인텐트 | 알람이 울릴 때 잠금 화면 위에 알람 끄기 화면을 보여주기 위함(알람 앱 용도). |
| 포그라운드 서비스 – 미디어 재생 | 알람이 울리는 동안 알람 소리를 재생하고, 사용자가 "끄기"를 누르면 즉시 종료합니다. 시연 영상이 필요하면 알람이 울리고 끄는 장면을 짧게 찍어 링크합니다. |

교대알람과 같은 권한 구성이라 그때 통과한 설명을 그대로 쓰면 됩니다.

## 12. 올리는 날 순서 (요약)

1. 패키지 이름 결정(0번) → 바꾼다면 그 뒤에 AAB를 다시 만든다

3. `cd android && ./gradlew bundleRelease` → `~/Desktop/세이람-1.0.0-vc1.aab`로 복사 (debug 서명 AAB는 올릴 수 없음 — 2026-10-13 기준 빌드 자체는 확인됨, 55MB)
4. main 병합 + GitHub Pages 켜기(2번) → 개인정보처리방침 주소 확인
5. 콘솔에서 앱 만들기(4번) → 앱 콘텐츠(5~7번) → 스토어 등록정보(8번) → 내부 테스트에 AAB 업로드
6. 비공개 테스트 12명·14일(9번) → 프로덕션 신청
