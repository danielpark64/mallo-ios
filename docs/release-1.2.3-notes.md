# 1.2.3 — 새 기능 문구 (2026-11-25 작성)

- 바뀐 것: 알람이 울리는 중 알림 본문을 누르면 알람이 꺼지지 않고 끄기 화면이 열림(Android), 알람을 저장할 때·시작할 때 "다른 앱 위에 표시"·알림이 꺼져 있으면 안내하고 바로 그 설정 화면으로, 배터리는 설정 화면 한 줄만(시작·저장 때 안 띄움), 끈 알람의 지난 알림 정리, 새 버전 안내(Android·iOS).
- 규칙: 본부/규칙/알람-맨앞.md(알람은 울리는 동안 맨 앞, 숨지 않음). Android·iOS 같은 버전으로 함께 제출.
