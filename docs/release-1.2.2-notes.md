# 1.2.2 — 새 기능 문구 (2026-11-24 작성)

- 바뀐 것: 받은 일정 링크를 누르면 세이람이 바로 열림(유니버설 링크·App Links, 새 주소 danielpark64.github.io/sayram/s/), 앱이 모르는 새 형식이면 "업데이트가 필요해요" 안내, 안내 페이지 스토어 버튼 "설치 / 업데이트".
- 11-24 사용자 지시: Play는 기기 확인 끝나는 대로 먼저, App Store는 1.2.1 심사가 끝나면 바로 제출.
