# 1.2.0 — 새 기능 문구 (Play 출시 노트 · App Store "이 버전의 새로운 기능")

2026-11-23 작성(초안, 스토어에는 아직 넣지 않음). Android 1.2.0(vc6) · iOS 1.2.0(빌드 13).
- 실제 변경: iOS 26 AlarmKit 알람(iOS만), 일정 보내기(카카오톡·문자, 말로 보내기, 받기 화면), 복사한 것 붙이기·사진 글자 읽기, 상세+수정 한 화면, 알람 소리 고르기(6개, 설정 기본 소리 + 일정마다).
- 카카오톡은 한국어 노트에만 쓰고, 다른 언어는 "메신저·문자"로 쓴다.
- 이모지·후원·외부 결제 문구 금지(체크리스트 3). Play는 언어별 500자, App Store는 4000자 이내(아래 모두 한참 안쪽).
- Play 언어 태그는 1.0.1 때와 같다. App Store 로캘은 1.1.1과 같은 9개: ko, en-US, ja, zh-Hans, zh-Hant, es-ES, fr-FR, de-DE, pt-BR.

## Play — 콘솔 출시 노트 칸에 블록째 붙여 넣기 (AlarmKit 줄 없음)
