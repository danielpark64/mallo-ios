# 세이람 1.2.4 — 출시앱 체크리스트 (2026-11-26)

바탕: `본부/규칙/출시앱-체크리스트.md`, `알람-android.md`, `알람-맨앞.md`, `워치-연동.md`, `고친버그-공통.md`(30~33). [직접] = Fable 확인, [에이전트] = 에이전트 보고.

바뀐 것:
- 스누즈가 재동기화(앱 다시 열기·기본 소리 변경 등)에 지워지던 버그 31을 고쳤다. 관련 코드: `lib/snoozeKeep.ts`, 네이티브 `cancelAllKeepSnooze`, AlarmKit `cancelAll(keep, rearm)`+`snz`.
- 결과 표시·삭제·시간 변경을 하면 걸려 있던 스누즈도 끈다(버그 30).
- iOS AlarmKit에 [5분 후 다시] 버튼과 카운트다운을 넣었다.
- iOS 알림 액션을 `opensAppToForeground: true`로 바꿨다(교대알람 1.6.4와 같게).
- 재동기화 때 Expo 알림을 전체 취소하지 않고, 읽은 목록만 지운다. 앱이 꺼진 채로 스누즈를 누르면 그 스누즈가 지워지던 경합을 막기 위해서다.
- 저장 직후 '맨 앞' 안내는 마지막으로 물은 지 하루가 지났을 때만 띄운다. 전에는 앱을 껐다 켤 때마다 다시 물었다.

## 1. 시작 전
- ✓ 참조: iOS 스누즈 버튼 구성은 교대알람 `715d90f`(버튼 순서·문구, 포그라운드 기본값)에서 가져왔다.
- ✓ 규칙 파일: 알람-android(두 경로 모두 예약·취소·재스케줄), 워치-연동(`customDismissAction: true` 유지).
- ✓ 심사 중: iOS 1.2.3(20) 심사 대기. 그래서 iOS 1.2.4는 TestFlight에만 올렸다.

## 2. 커밋 전
- ✓ 자동 검사: tsc 통과, jest 920/920 [직접]. verify-fix·alarm-logic은 커밋을 막을 문제 없음 [에이전트]. verify-fix가 짚은 경합은 고쳤다 [직접].
- ✓ Android 실기기(A32, vc11) [에이전트, 캡처 직접 확인]: 스누즈 뒤 앱 종료·다시 열기 유지 / 소리 변경 뒤 유지 / 결과 표시·삭제·시간 변경 때 함께 꺼짐 / 끄기 / FATAL 0. 모두 진동만으로 시험했다.
- △ '맨 앞' 안내 하루 간격: 단위 테스트만 했다. 기기 확인은 안 했다.
- ✓ Note10+(vc11) [에이전트, 캡처 직접 확인]: 스누즈 → am kill → 다시 열기 뒤에도 유지, 5분 뒤 '다시 알림' 카드, 끄기 정상, FATAL 0. 오버레이가 꺼져 있어 홈 화면에서는 헤드업만 떴다(알려진 한계). 하루 간격 안내는 첫 안내가 이미 하루 안에 있어 '다시 안 뜸'만 확인.
- ✓ iOS 실기기(iPad mini 6, iPadOS 27, 빌드 24 개발 서명) [에이전트, 캡처 직접 확인]: ① 진동만 알람, 앱 종료 상태에서 [5분 후 다시] → 정확히 5분 뒤 다시 옴 ② 앱 종료 상태에서 [알람 끄기] → +2분 재알림 안 옴(+1분은 누르기 전에 이미 옴). 캡처 `~/Desktop/세이람-작업도구/captures/mini124/`.
- ✓ AlarmKit 소리 알람(미니, 11-26 13:28, 소리 허용 시간) [직접 캡처 확인]: 잠금 풀린 상태라 위쪽 배너(반복 아이콘·X)로 울림 → 반복 아이콘([5분 후 다시]) → 잠금 화면 남은 시간 '4:41' 표시 → 13:33:46 다시 울림 → X로 끔. 캡처 `~/Desktop/세이람-작업도구/captures/mini124s/`. 배너에서는 버튼이 글자 없이 아이콘만 보인다(잠금 상태 전체 화면의 글자는 미니 잠금이 안 돼 못 봄).
- ☐ 워치: 기기 없음.
- 알고 있는 한계(1.2.4 회귀 아님):
  - '다른 앱 위에 표시'가 꺼져 있으면 다른 앱 위로 울림 화면이 뜨지 않는다. 설계상 한계이고 앱이 안내한다(1.2.3 체크리스트와 같다).
  - 스누즈가 걸린 5분 동안 상세 배지가 '지난 일정 (알림 없음)'으로 보인다. 고치지 않고 둔다.
  - 미니에서 일정 저장 직후 달력 머리가 잠깐 '2024년 11월'로 보였다(다시 열면 정상, 원인 안 봄 — 1.2.4 변경과 무관해 보임).
  - 1.2.3에서 건 JS 스누즈는 업데이트 직후 첫 재동기화 때 지워진다.
